街道分报告生成器使用指南

一、程序用途
本程序用于批量生成街道分报告相关成果，主要输出：
1. 街道案件明细表
2. 街道环境建设管理工作运行情况分析报告
3. 专项表格汇总.xlsx

二、启动方式
1. 直接双击运行程序
2. 命令行运行：
   python app.py

三、界面说明
1. 左侧依次显示：
   - 案件明细表模板
   - 分析报告模板
   - 输出目录
   - 已上传文件列表
2. 右侧按钮纵向排列：
   - 添加文件
   - 生成
   - 仅生成表格提取表
   - 打开输出目录
   - 清空
3. 进度条为绿色，生成结束后会显示生成用时。

四、文件选择规则
1. “添加文件”支持一次多选文件。
2. 支持的文件类型：
   - .xlsx
   - .docx
   - .doc
   - .wps
3. 已选文件会逐行显示在左侧“大文本框”中。
4. 程序会自动跳过：
   - 以 ~$ 开头的临时文件
   - 文件名包含“模板”的文件
   - 路径中包含“提交格式”的文件

五、主数据文件要求
1. 主数据 Excel 必须存在。
2. 主数据文件名必须包含：
   - 现场检查用数据
3. 程序会在输入文件中查找包含该关键词的 xlsx 文件作为主数据源。

六、Word/WPS 材料文件规则
1. Word/WPS 文件名可以比较乱，不要求固定格式。
2. 程序会依据表格标题和固定分类关键词识别对应内容。
3. 建议文件名尽量保留业务关键词，方便人工识别：
   - 道路清扫保洁
   - 垃圾管理
   - 城市家具
   - 背街小巷
   - 网格化主动治理
   - 综合执法

七、两个模板文件
1. 案件明细表模板
   - 默认：街道案件明细表模板.xlsx
2. 分析报告模板
   - 默认：街道环境建设管理工作运行情况分析报告模板.docx
3. 两个模板文件是独立配置项。
4. 模板文件只读取，不修改。

八、输出文件
1. 每个街道会生成一个子目录。
2. 子目录内包含：
   - {月份}{街道}案件明细表.xlsx
   - {月份}{街道}环境建设管理工作运行情况分析报告.docx
3. 根目录还会生成：
   - 专项表格汇总.xlsx

九、专项表格汇总
1. 每个 sheet 自动适应列宽。
2. sheet 名优先使用源文件中的表格标题。
3. 没有标题时，回退为“文件名-序号”。

十、报告模板动态规则
1. 报告按内容动态生成，不再把所有专题硬写死。
2. 空内容专题会自动省略。
3. 被省略的专题后续编号会自动重排。
4. 动态章节由 `report_sections` 统一控制，城市家具、背街小巷、网格、综合执法、工作建议会按实际内容顺延编号。

十一、发布目录结构
1. 街道分报告生成器.exe 放在发布目录根目录。
2. templates 存放随程序发布的模板文件。
3. docs 存放程序使用指南、程序逻辑、README 等说明文件。
4. _internal 存放运行依赖文件，不需要手动打开或修改。

十二、维护说明
1. 本指南需要和程序代码同步更新。
2. 修改模板、编号规则、文件识别规则、输出规则后，都要回头更新本文件。
